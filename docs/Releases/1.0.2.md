# WorldEditorPixel 1.0.2

- **Tag:** `v1.0.2`
- **Date:** 2026-08-24
- **Platform:** Windows 10/11 x64
- **Artifact:** `WorldEditorPixel-1.0.2-win-x64.exe`

WorldEditorPixel 1.0.2 completes keyboard map authoring and makes Resource and Season generation visibly responsive before large-world snapshot preparation begins. Project and runtime file schemas remain unchanged.

## Improved

- Adds **View → Focus map** and `F6` as discoverable routes to the campaign canvas.
- Extends the keyboard tile cursor with ten-tile, viewport, and row-edge movement, automatic viewport following, and cursor-centred `+` / `-` zoom while preserving one-command `Enter` stamping and `Space` pin/inspect behavior.
- Shows the disabled Generate control and indeterminate progress state before Resource or Season generation reads the first terrain tile.
- Keeps snapshot preparation cancellation-aware, avoids hidden large-world captures when toggling derived seeds, and leaves deterministic generation worker-backed.

## Compatibility

- Editable project format remains version 2.
- Compact `.kworld` runtime package remains version 3.
- Readable `world-editor-pixel-runtime-json` remains version 1.
- Existing projects that satisfy the shared `250,000`-tile limit remain compatible.

## Download and integrity

Download both release assets:

- `WorldEditorPixel-1.0.2-win-x64.exe`
- `SHA256SUMS.txt`

Compare the executable's SHA-256 with the checksum file before running it. The executable is self-contained and does not require a separately installed .NET runtime. It is not code-signed, so Windows SmartScreen may ask for confirmation.
