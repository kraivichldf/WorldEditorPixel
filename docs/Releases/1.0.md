# WorldEditorPixel 1.0

- **Tag:** `v1.0.0`
- **Date:** 2026-08-24
- **Platform:** Windows 10/11 x64
- **Artifact:** `WorldEditorPixel-1.0-win-x64.exe`

WorldEditorPixel 1.0 is the first stable public build of the standalone campaign-scale terrain editor. The release is one self-contained executable and does not require a separately installed .NET runtime.

## Highlights

- Author exact square campaign grids in kilometres, with one complete terrain type and whole-metre centre height per tile.
- Preview and accept deterministic Continental, Island, Archipelago, directional Coast, Sea in Center, and Land Only worlds.
- Paint built-in/custom terrain, Resources with potential, and zero or more built-in/custom Season Occurrences per tile.
- Build connected River, Large River, and bounded River Junction routes while automatic coast edges preserve original land identity.
- Regenerate terrain, Resources, or Seasons through Current/Candidate review before authority changes.
- Save editable project folders and export either compact `.kworld` version 3 packages or readable single-file `.world.json` version 1 data for engine importers.
- Use the compact Windows 98-style desktop shell with the multi-resolution WorldEditorPixel terrain-map icon.

## Download and integrity

Download both files from the GitHub release:

- `WorldEditorPixel-1.0-win-x64.exe`
- `SHA256SUMS.txt`

Compare the executable's SHA-256 with the checksum file before running it. This release is not code-signed, so Windows SmartScreen may ask for confirmation.

## Compatibility boundary

Version 1.0 keeps the existing version-2 editable terrain project contract, optional Resource/Season sidecars, `.kworld` runtime package version 3, and `world-editor-pixel-runtime-json` version 1. It does not add a gameplay runtime, engine plugin, networking, database, roads, settlements, or 3D world renderer.
