# WorldEditorPixel 1.0.1

- **Tag:** `v1.0.1`
- **Date:** 2026-08-24
- **Platform:** Windows 10/11 x64
- **Artifact:** `WorldEditorPixel-1.0.1-win-x64.exe`

WorldEditorPixel 1.0.1 is a safety and accessibility patch for the standalone campaign-scale editor. Project and runtime file schemas remain unchanged.

## Fixed

- Enforces one `250,000`-tile maximum for Blank/generated creation, regeneration, project open/import, save, canvas rendering, and both runtime exports. Oversized version-2 projects fail before sidecars load; oversized version-1 imports fail before chunk payloads load.
- Removes the unsafe Blank-world exception from New World and disables creation when the exact grid exceeds the shared limit.
- Makes the campaign canvas keyboard-operable: Tab focus, high-contrast tile/area cursor, arrow movement with viewport following, `Enter` for one active Terrain/Resource/Season command, and `Space` for pin/inspect.

## Compatibility

- Editable project format remains version 2.
- Compact `.kworld` runtime package remains version 3.
- Readable `world-editor-pixel-runtime-json` remains version 1.
- Projects containing at most `250,000` campaign tiles remain compatible. Larger projects are deliberately rejected because the editor cannot safely render and process them.

## Download and integrity

Download both release assets:

- `WorldEditorPixel-1.0.1-win-x64.exe`
- `SHA256SUMS.txt`

Compare the executable's SHA-256 with the checksum file before running it. The executable is self-contained and does not require a separately installed .NET runtime. It is not code-signed, so Windows SmartScreen may ask for confirmation.
